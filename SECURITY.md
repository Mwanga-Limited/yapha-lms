# Security policy

Yapha LMS is maintained by Mwanga Limited (Nigeria).

## Reporting a vulnerability

Email **tech@mwanga.ng** with the subject "Security: Yapha LMS". Please include the affected URL or component, steps to reproduce, and the impact you see. Do not open a public GitHub issue and do not access data that is not yours.

We aim to acknowledge reports within 3 working days and to give a status update within 10 working days. We will credit reporters who want it once a fix is released.

## Supported versions

Only the latest release (currently 0.9.x) receives security fixes.

## Scope

Tenant isolation, authentication and two-step sign-in, file uploads, and the platform console are the most sensitive areas. See "Security notes" in README.md and `deploy/RUNBOOK.md`.
